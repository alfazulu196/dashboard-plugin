# Modular Dashboard for XFCE (Модульный Дашборд для XFCE)

Этот скрипт предоставляет гибкое решение для создания настраиваемой информационной панели в XFCE с помощью плагина "Generic Monitor". Он позволяет отображать различные системные метрики и уведомления в одном, легко настраиваемом виджете.

**Важно:** Для корректной работы числовых значений, скрипт устанавливает переменную окружения `LC_NUMERIC="C"`.

## Особенности

-   **Модульная структура:** Определяйте и настраивайте виджеты в одном файле `dashboard.json`.
-   **Различные метрики:** CPU, память, диск, нагрузка, топ-процесс, температура CPU, аптайм, ошибки журнала, неудачные попытки входа.
-   **Настраиваемые иконки:** Используйте любые символы или эмодзи для виджетов.
-   **Цветовая индикация:** Визуальные предупреждения на основе пороговых значений (например, для температуры CPU).
-   **Критические оповещения:** Настраиваемые уведомления для важных событий (например, при множественных неудачных попытках входа).
-   **Детальный отчет по клику:** Клик по плагину выводит системное уведомление с подробной информацией по всем виджетам.

## Установка

Установка очень проста и выполняется одной командой. Откройте терминал и выполните:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/alfazulu196/dashboard-plugin/main/install.sh)
```

**ВАЖНО:** Замените `%%USER%%` на ваше имя пользователя GitHub и `%%REPO%%` на имя вашего репозитория.

Скрипт установки загрузит необходимые файлы, создаст директорию `$HOME/.local/share/dashboard-plugin` и сделает главный скрипт исполняемым.

## Использование (Настройка плагина XFCE Generic Monitor)

После установки:

1.  **Добавьте плагин "Generic Monitor"** ("Общий монитор") на вашу панель XFCE.
2.  В **"Свойствах"** плагина укажите полный путь к главному скрипту:
    ```
    $HOME/.local/share/dashboard-plugin/dashboard.sh
    ```
3.  Установите **"Период"** обновления (например, `3` секунды).
4.  Убедитесь, что галочка "Создать метку в панели" **снята**.

## Настройка виджетов (`dashboard.json`)

Откройте файл `$HOME/.local/share/dashboard-plugin/dashboard.json`. В нем вы можете настроить:

-   **`separator`**: Разделитель для виджетов.
-   **`widgets`**: Массив объектов, где каждый объект представляет один виджет.

### Иконки для виджетов (Emoji)
Каждому виджету можно добавить поле `"icon"` с любым символом или эмодзи.

### Цветовая индикация по порогам
Для некоторых виджетов (например, `cpu_temp`) можно задать пороги `warning` и `critical` для изменения цвета.

### Критические оповещения (для `auth_failures`)
Для виджета `auth_failures` вы можете настроить отправку критического уведомления. Уведомление останется на экране, пока вы его не закроете.
-   **`thresholds.critical`**: Порог, при превышении которого сработает уведомление.
-   **`alert_on_threshold`**: Установите `true`, чтобы включить эту функцию.

**Пример `dashboard.json` со всеми функциями:**
```json
{
  "separator": " | ",
  "widgets": [
    { "type": "cpu", "icon": "💻" },
    { "type": "memory_detailed", "icon": "🧠" },
    { "type": "disk", "icon": "💾" },
    { "type": "load", "icon": "📈" },
    { "type": "top_process", "icon": "🔝" },
    {
      "type": "cpu_temp",
      "icon": "🌡️",
      "thresholds": {
        "warning": 70,
        "critical": 85
      }
    },
    { "type": "uptime", "icon": "⏳" },
    { "type": "journal_errors", "icon": "⚠️" },
    {
      "type": "auth_failures",
      "icon": "🛡️",
      "thresholds": {
        "critical": 20
      },
      "alert_on_threshold": true
    }
  ]
}
```

## Зависимости и важные примечания

Для работы скрипта могут потребоваться следующие утилиты. Установите их с помощью вашего пакетного менеджера (например, `apt`, `dnf`, `pacman`):

-   `jq`: Легковесный и гибкий процессор JSON в командной строке.
-   `lm-sensors`: Для получения информации о температуре CPU.
-   `curl`: Для установки скрипта.
-   `notify-send`: Для системных уведомлений.

### Для виджета `auth_failures`
Для доступа к `/var/log/auth.log` скрипту нужны права на чтение. Обычно для этого ваш пользователь должен состоять в группе `adm`. Проверить это можно командой `groups`. Если группы `adm` нет, добавьте пользователя в нее:
`sudo usermod -a -G adm ваше_имя_пользователя`
(Потребуется перезайти в систему).

### Для виджета `cpu_temp`
Убедитесь, что у вас установлен `lm-sensors` и он настроен (`sudo sensors-detect`).

### Проблема с зависанием плагина
Если плагин перестал отвечать, перезапустите панель XFCE командой: `xfce4-panel -r`.
